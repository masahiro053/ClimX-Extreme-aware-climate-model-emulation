# ClimX-Extreme-aware-climate-model-emulation

## 📌 コンペティション概要
- **リンク:** [ClimX: Extreme-aware climate model emulation](https://www.kaggle.com/competitions/climx-main-track)
- **目的:** 温室効果ガス（GHG）などの入力データから、将来の極端な気象（熱波、干ばつなど）を予測できる高速・高精度なAI気候エミュレータを構築する。
- **タスク:** 毎日の7つの気象変数の2Dマップ（解像度1度）を予測。
- **評価指標:** 正規化Nash-Sutcliffe効率（**nNSE**）。予測した7つの変数から15種類の「極端気象インデックス」を計算し、その再現度で評価される（インデックスの直接予測は不可）。
- **期間:** ~ 2026/12/15

## 🎯 戦略・方針メモ
- **Loss関数の工夫:** 評価指標である極端気象インデックスを意識し、単純なMSEではなく外れ値に強い、あるいはJAXを活用した微分可能なカスタムLossの設計を探る。
- **データハンドリング:** 約200GBの重いデータ（NetCDF/Zarr）をいかに効率的にDataloaderに組み込むかが鍵。
- **Notebook公開:** EDAや軽量版（ClimX-lite）を用いたベースラインを公開し、Notebook Expert（Bronzeの次のメダル）を狙う。
